# DLO Rule Catalog

This directory contains an interpretive, machine-readable catalog derived from `docs/dlo/instrucoes-preenchimento/knowledge/`.

The Markdown files under `knowledge/` remain authoritative. If a catalog entry conflicts with its cited source, the source text prevails. Entries with unresolved scope, dependencies, classifications, or extraction issues are recorded in `review-required.md` rather than inferred here.
