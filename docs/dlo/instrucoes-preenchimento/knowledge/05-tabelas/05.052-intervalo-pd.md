### Tabela 052 – Intervalo de PD (Probabilidade de Descumprimento)

* Tabela 053 define o intervalo em que a probabilidade de descumprimento (em percentual) está inserida - Res. BCB 303/2023.

|  |  |
| --- | --- |
| **DOMÍNIO** | **DESCRIÇÃO** |
| 01 | de 0.00 a < 0,15% |
| 02 | de 0,15 a < 0,25% |
| 03 | de 0,25 a < 0,50% |
| 04 | de 0,50 a < 0,75% |
| 05 | de 0,75 a < 2,50% |
| 06 | de 2,50 a < 10,00% |
| 07 | de 10,00 a < 100,00% |
| 08 | 100,00% (descumprimento) |
