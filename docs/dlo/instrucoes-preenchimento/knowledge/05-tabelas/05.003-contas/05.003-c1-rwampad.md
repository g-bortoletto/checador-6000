##### Detalhamento da Apuração do RWAMPAD 770 RWA PARA RISCO DE MERCADO

Corresponde ao total de RWA para risco de mercado (RWAMPAD para instituições que utilizam modelo padronizado e RWAMINT para as instituições autorizadas a utilizar modelo interno), apurado segundo modelo padronizado. Corresponde a seguinte fórmula: SALDO (800) + SALDO (810) + SALDO (820) + SALDO (830) + SALDO (840) + SALDO (850) + SALDO (860) + SALDO (861) + SALDO (862).

Para instituições autorizadas a utilizar modelo interno de risco de mercado. Corresponde a seguinte fórmula: MAX (SALDO (865) + SALDO (866); SM \* (SALDO (800) + SALDO (810) + SALDO (820) + SALDO (830) + SALDO (840) +

SALDO (850) + SALDO (860)) + SALDO (861) + SALDO (862). Em que SM representa o fator de transição para modelo interno: 90% no primeiro ano de uso e 80% nos demais anos.
