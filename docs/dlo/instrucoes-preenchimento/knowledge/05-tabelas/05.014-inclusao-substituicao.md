### Tabela 014 – Indicador de inclusão e substituição de documento

* Tabela 014 define o valor do campo “tipoEnvio” para indicação de que se trata de inclusão ou substituição de documento.

|  |  |
| --- | --- |
| **DOMÍNIO** | **DESCRIÇÃO** |
| I | Inclusão; |
| D | Substituição por determinação; |
| E | Substituição espontânea. |

Observação, os domínios acima indicados também são aplicáveis a novos envios em situações em que o documento tenha sido rejeitado na entrada, em críticas de “entrada” ou de processamento (mensagem de rejeição do arquivo pelo STA/sistema de negócios). Exemplo 1: a instituição remete o documento original (com o domínio “I”) e recebe mensagem de que o documento foi rejeitado pelo STA/sistema de negócios, o novo documento a ser remetido também deverá receber o código “I”. Exemplo 2: a instituição remeteu o documento e recebeu mensagem via CRD de que o documento apresenta indícios de erro, em que há demanda para substituição do documento remetido, com base nessa indicação a instituição remete um novo documento, e utiliza o domínio “D”, caso este novo arquivo seja rejeitado via STA/sistema de negócios, a instituição deverá observar os erros apontados e fazer novo envio, utilizando novamente o domínio “D”.
