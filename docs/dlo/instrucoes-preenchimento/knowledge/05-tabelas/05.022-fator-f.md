### Tabela 022 – Fator “F” aplicável

* Tabela 022 define os fatores F do art. 4º da Res. CMN 4.958/21 e Res. BCB 200/22.

|  |  |
| --- | --- |
| **FATOR** | **APLICAÇÃO** |
| 8% | Instituições caracterizadas como Tipo 1 ou Tipo 3, exceto cooperativa de crédito singular não vinculada a uma cooperativa central de crédito; |
| 12% | Cooperativa de crédito singular não vinculada a uma cooperativa central de crédito. |
