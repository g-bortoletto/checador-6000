### Tabela 002 – Informação se o limite foi enviado

* Tabela 002 define se no documento a instituição deve prestar a informação para cada um dos limites definidos na Tabela 001. Assumindo que a instituição esteja sujeita a determinado limite, deverá informar o atributo “enviado”

= “S” e informar o conjunto de contas que tratam do referido limite. Caso a instituição não esteja sujeita a algum dos limites, conforme normativos, deverá informar “N”.

|  |  |
| --- | --- |
| **CÓDIGO** | **DESCRIÇÃO** |
| S | SIM – as informações relativas ao limite são devidas e foram encaminhadas no documento. |
| N | NÃO – as informações relativas ao limite não são devidas e não foram encaminhadas no documento. |
